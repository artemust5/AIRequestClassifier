# AI Request Classifier

Python-сервіс для автоматичної класифікації та структурування запитів від різних відділів. 

## Запуск

1. **Встановлення залежностей:**
   `pip install -r requirements.txt`

2. **Змінні середовища:**
   Створіть файл `.env` на основі `.env.example` та додайте свій ключ для Gemini.
   *(Для роботи Telegram-сповіщень також додайте `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`)*

3. **Вхідні дані:**
   Переконайтесь, що файл `input_requests.csv` лежить у кореневій директорії.

4. **Виконання:**
   `python main.py`

## Запуск через Docker

1. **Збірка образу:**
   `docker build -t ai-classifier .`

2. **Запуск контейнера (із підтягуванням ключів):**
   `docker run --env-file .env ai-classifier`

## Особливості проєкту

* **Telegram-інтеграція:** Автоматичне надсилання згенерованого результату (`report.md`) у вказаний чат.
* **Контейнеризація:** Повністю ізольоване середовище завдяки налаштованому `Dockerfile`.
* **CI/CD:** Пайплайн GitHub Actions для автоматичного тестування збірки Docker-образу.
* **Асинхронність:** Швидка паралельна обробка запитів завдяки `asyncio` та `aiohttp`.

## Архітектура рішення (Architecture)
Проєкт побудовано з використанням принципів Clean Architecture та SOLID. Інтерфейси вводу/виводу (`io_handlers.py`) повністю ізольовані від бізнес-логіки обробки даних через LLM. Це дозволяє легко масштабувати сервіс та підміняти джерела даних (наприклад, переключитися з CSV на базу даних) без зміни ядра класифікатора.

## Алгоритм роботи (Data Pipeline)
1. **Ініціалізація:** Валідація наявності необхідних полів у вхідному `.csv` файлі.
2. **Батчинг:** Групування записів для оптимізації кількості запитів до API.
3. **Класифікація:** Відправка даних до Gemini API (temperature=0.0) із жорсткою валідацією вихідного формату через Pydantic схеми. У разі збою застосовується логіка repair (retry).
4. **Експорт:** Збереження типізованого результату в JSON та генерація фінального Markdown-звіту.
