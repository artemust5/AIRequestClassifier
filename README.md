# AI Request Classifier

Python-сервіс для автоматичної класифікації та структурування запитів від різних відділів. 

## Запуск

1. **Встановлення залежностей:**
   `pip install -r requirements.txt`

2. **Змінні середовища:**
   Створіть файл `.env` на основі `.env.example` та додайте свій ключ для Gemini.

3. **Вхідні дані:**
   Переконайтесь, що файл `input_requests.csv` лежить у кореневій директорії.

4. **Виконання:**
   `python main.py`
